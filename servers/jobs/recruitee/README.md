# Recruitee MCP server

Category: **jobs** · Docs: https://docs.recruitee.com/reference/careers-site-api · Verified: 2026-09-25

Served by [platform-mcp-hub](https://github.com/tonyyang0504/platform-mcp) from `catalog/jobs/recruitee.json`; edit the catalog, not this file.

## Tools

- `search` — `GET /offers/` (https://docs.recruitee.com/reference/offers)
- `apply` — `POST /offers/{id}/candidates` (https://docs.recruitee.com/reference/offersoffer_idcandidates)
- ~~`me`~~ not offered: The Careers Site API has no account endpoint (its token covers only /offers, /offers/:id and /offers/:offer_slug/candidates).
- ~~`get_posting`~~ not offered: The Careers Site API reference documents only the offers list and the apply endpoint; the documented /offers/:id is the ATS API (https://api.recruitee.com/c/{company_id}/offers/{id}) with a different token. Re-read the record from the search hit.
- ~~`list_messages`~~ not offered: No candidate messaging in the Careers Site API.

## Credentials

- `PLATFORM_MCP_RECRUITEE_CAREERS_TOKEN` — Careers Site API token generated by a Recruitee user of the company, sent as `X-Careers-Sites-Token`; 'Deadline for introducing the token to calls is 10 February 2027. Calls without the authorization header will return the 401 Unauthorized error'.
- `PLATFORM_MCP_RECRUITEE_COMPANY_SUBDOMAIN` — The company's Recruitee careers-site subdomain, e.g. 'recruiteedemo' in https://recruiteedemo.recruitee.com.
- `PLATFORM_MCP_RECRUITEE_APPLICANT_NAME` — Candidate full name sent as candidate.name by apply (required by Recruitee for applications).
- `PLATFORM_MCP_RECRUITEE_APPLICANT_EMAIL` — Candidate e-mail sent as candidate.email by apply (required by Recruitee for applications).
- `PLATFORM_MCP_RECRUITEE_APPLICANT_PHONE` — Candidate phone sent as candidate.phone by apply (required unless the offer's form makes it optional).

## Run

**Unpublished — run from source.** platform-mcp-hub is not on PyPI or npm yet; do not install the name from a registry until it is (anyone could register it first).

    uvx --from git+https://github.com/tonyyang0504/platform-mcp platform-mcp-hub serve recruitee   # Python, stdio
    git clone https://github.com/tonyyang0504/platform-mcp && cd platform-mcp && uv run platform-mcp-hub serve recruitee
    cd runtime/typescript && npm ci --ignore-scripts && npm run build && node dist/cli.js serve recruitee   # TypeScript

Add `--http --port 8000` for Streamable HTTP on 127.0.0.1. Registry name: `io.github.tonyyang0504/recruitee-mcp`. Python and TypeScript serve identical tools.
