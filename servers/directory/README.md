# platform-mcp-hub directory

One MCP server that knows the whole catalog: every platform per category, whether it has a documented API, whether
platform-mcp-hub serves it, which verbs it offers (and which it does not, with the reason), the credential environment
variables, and the command that starts it.

| tool | what it answers |
|---|---|
| `list_categories` | categories, platform counts, served counts, shared verbs |
| `list_platforms` | browse or search by category, text, `served_only`, `has_api`, `region`; paginated |
| `describe_platform` | one platform: API facts, tools, `not_offered`, credentials, run commands |
| `search_capabilities` | platforms that support a verb (`search`, `publish_text`, `get_ticker`, ...) or a capability keyword |

All tools are read-only over the snapshot `catalog/directory.json` (regenerated by `python tools/gen_all.py`).

Run (**unpublished — run from source** until platform-mcp-hub is on PyPI and npm; see `docs/RELEASE_CHECKLIST.md`):

```bash
uvx --from git+https://github.com/tonyyang0504/platform-mcp platform-mcp-hub directory          # stdio
uvx --from git+https://github.com/tonyyang0504/platform-mcp platform-mcp-hub directory --http   # Streamable HTTP on 127.0.0.1:8000/mcp
```

Once published: `uvx platform-mcp-hub directory` or `npx -y platform-mcp-hub directory`. `server.json` and
`manifest.json` here are its registry metadata (`io.github.tonyyang0504/platform-mcp-hub`).
