# ManoMano MCP server

Category: **ecommerce_channels** · Docs: https://www.manomano.dev/ · Verified: 2026-09-25

Served by [platform-mcp-hub](https://github.com/tonyyang0504/platform-mcp) from `catalog/ecommerce_channels/manomano.json`; edit the catalog, not this file.

## Tools

- `me` — `GET /api/v1/offer-information/offers` (https://www.manomano.dev/#get_offers_info)
- `update_listing` — `PATCH /api/v2/offer-information/offers` (https://www.manomano.dev/#update_offers)
- `set_inventory` — `PATCH /api/v2/offer-information/offers` (https://www.manomano.dev/#update_offers)
- `list_orders` — `GET /orders/v1/orders` (https://www.manomano.dev/#get-a-list-of-orders)
- `mark_shipped` — `POST /orders/v1/shippings` (https://www.manomano.dev/#create-shippings)
- ~~`create_listing`~~ not offered: Offers are created through the product catalogue feed (Taxonomy API lists the feed fields) or PUT /api/v1/offers with the full offer and product attributes; the vocabulary lacks the category, EAN, brand and shipping data these need.
- ~~`end_listing`~~ not offered: No offer delete/deactivate call in the Partners API collection; an offer goes offline through the feed or by setting its stock to 0 (use set_inventory).

## Credentials

- `PLATFORM_MCP_MANOMANO_API_KEY` — API key generated by a Toolbox Admin under Settings > API keys (shown once; one key serves all of the seller's contracts); sent as the x-api-key header.
- `PLATFORM_MCP_MANOMANO_SELLER_CONTRACT_ID` — Numeric seller contract id (one per ManoMano market and delivery type, shown in Toolbox); every call is scoped to it.

## Run

**Unpublished — run from source.** platform-mcp-hub is not on PyPI or npm yet; do not install the name from a registry until it is (anyone could register it first).

    uvx --from git+https://github.com/tonyyang0504/platform-mcp platform-mcp-hub serve manomano   # Python, stdio
    git clone https://github.com/tonyyang0504/platform-mcp && cd platform-mcp && uv run platform-mcp-hub serve manomano
    cd runtime/typescript && npm ci --ignore-scripts && npm run build && node dist/cli.js serve manomano   # TypeScript

Add `--http --port 8000` for Streamable HTTP on 127.0.0.1. Registry name: `io.github.tonyyang0504/manomano-mcp`. Python and TypeScript serve identical tools.
