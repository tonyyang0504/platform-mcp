Scope: the 124 served catalog entries whose adapter auth type is `none`. 37 of them are keyless only in the
sense that they sign requests themselves (`auth.type: none` + `auth.sign`) or need operator config, so they
still require credentials; for those the check stops at: the server starts, lists its tools, and answers a
clean `auth_error` naming the exact environment variables. `sales/us_sec_edgar` is counted there too: SEC fair
access requires the operator's real contact e-mail in the User-Agent, and the verifier never invents one.

Method per server: initialize + tools/list over stdio, then every READ tool (write tools are listed but never
called): the list tool with a query that should match, the detail tool with an id taken from that result, the
same detail tool with a nonexistent id (must be a clean tool error), and page 2 via the tool's own `next_page` /
`next_cursor` (must not repeat page 1). Every result is validated against the vocabulary output schema — the
same check the Python MCP client applies to `structuredContent` (a mismatch raises there). Calls are
sequential, ≥ 1 s apart and never faster than the entry's `rate_per_second`; Retry-After is honoured; nothing
is retried. Public, non-personal config was supplied where a server needs a board name (listed in the notes).
